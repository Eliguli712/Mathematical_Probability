# Midterm 1 Study Materials / Lernmaterialien zur ersten Zwischenprüfung

## English

This folder contains the current English Mathematical Statistics Midterm 1
review handout and the Memory Inertia Lab deliverables.

| File | Description |
|---|---|
| `Mathematical_Statistics_Midterm_1_Practice_and_Solutions.pdf` | Standard LaTeX practice set and solutions, based on the instructor's September 23 exam announcement and Carlos Fernandez-Granda's September 25 correction. The corrected Second District poll counts are **Trump 210** and **Harris 270**. The practice set contains no coding or device-based questions. |
| `memory-inertia-lab.html` | Self-contained interactive report. Use the control in the upper-right corner to switch between English and German. |
| `memlab.zip` | Complete reproducible project, including the bilingual report, source modules, data, generated tables, and 25 numerical tests. `run_all.py` preserves the English/German switch when rebuilding the report. |
